# SMS Forwarder (فوروارد شرطی پیامک)

یک اپلیکیشن ساده‌ی اندروید که پیامک‌های دریافتی را بررسی می‌کند؛ اگر **فرستنده** با شماره‌ی تعریف‌شده در تنظیمات مطابقت داشت (شرط)، متن پیامک را به یک **شماره‌ی مقصد** دیگر فوروارد می‌کند.

## چگونه کار می‌کند

- `SmsReceiver.kt` یک `BroadcastReceiver` است که روی `android.provider.Telephony.SMS_RECEIVED` ثبت شده و با رسیدن هر پیامک جدید اجرا می‌شود.
- شماره‌ی فرستنده با شماره‌ی ذخیره‌شده در `Prefs` (شرط) مقایسه می‌شود (بعد از نرمال‌سازی ساده‌ی فرمت شماره).
- در صورت تطابق، با `SmsManager` پیامک (همراه با پیش‌وند «فوروارد از ...») به شماره‌ی مقصد ارسال می‌شود.
- `MainActivity.kt` یک صفحه‌ی ساده برای وارد کردن «شماره شرط»، «شماره مقصد»، فعال/غیرفعال کردن قابلیت، و درخواست مجوزهای لازم (`RECEIVE_SMS`, `SEND_SMS`) است.

## گرفتن فایل APK قابل نصب (بدون نیاز به نصب Android Studio)

این پروژه شامل یک GitHub Actions workflow آماده (`.github/workflows/build-apk.yml`) است که به‌صورت خودکار پروژه را کامپایل کرده و یک APK قابل‌دانلود می‌سازد:

1. یک ریپازیتوری جدید (می‌تواند Private باشد) در [github.com](https://github.com) بسازید.
2. محتوای این پوشه (`SmsForwarder`) را در آن push کنید:
   ```bash
   cd SmsForwarder
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin <آدرس-ریپازیتوری-شما>
   git push -u origin main
   ```
3. وارد تب **Actions** در صفحه‌ی ریپازیتوری در GitHub شوید؛ یک workflow به نام «Build APK» به‌طور خودکار اجرا می‌شود (معمولاً ۲ تا ۴ دقیقه طول می‌کشد).
4. پس از پایان اجرا (علامت ✅ سبز)، روی همان اجرا کلیک کنید؛ در پایین صفحه بخش **Artifacts** یک فایل به نام `SmsForwarder-debug-apk` می‌بینید — آن را دانلود کنید. داخلش فایل `app-debug.apk` است.
5. فایل APK را به گوشی اندرویدتان منتقل کنید (از طریق لینک دانلود مستقیم، تلگرام به خودتان، یا کابل) و آن را نصب کنید.
   - چون این APK امضای رسمی Google Play را ندارد (نسخه‌ی debug است)، اندروید پیام «منبع ناشناس» می‌دهد؛ باید گزینه‌ی **نصب از منابع ناشناس** را برای همان اپ (مثلاً فایل‌منیجر یا مرورگر) موقتاً فعال کنید.
6. هنگام اولین اجرا، دکمه‌ی «اعطای مجوزهای پیامک» را بزنید و دسترسی خواندن/ارسال پیامک را تأیید کنید.
7. «شماره‌ی شرط» (شماره‌ای که پیامک‌هایش باید فوروارد شود) و «شماره‌ی مقصد» را وارد و ذخیره کنید.
8. از این پس، هر پیامکی که از شماره‌ی شرط برسد، به‌صورت خودکار به شماره‌ی مقصد فوروارد می‌شود.

> می‌توانید این workflow را دستی هم اجرا کنید: تب Actions → workflow «Build APK» → دکمه‌ی **Run workflow**.

## روش جایگزین: ساخت با Android Studio

اگر به GitHub دسترسی ندارید یا ترجیح می‌دهید روی کامپیوتر خودتان بسازید:

1. پوشه‌ی `SmsForwarder` را در **Android Studio** باز کنید (File → Open).
2. اجازه دهید پروژه Sync شود (Gradle Wrapper از قبل در پروژه قرار دارد).
3. از منو: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. پس از پایان ساخت، لینک «locate» در اعلان پایین صفحه را بزنید تا فایل `app-debug.apk` را پیدا کنید (معمولاً در `app/build/outputs/apk/debug/`).
5. مراحل ۵ تا ۸ بالا (نصب، مجوزها، تنظیم شماره‌ها) را دنبال کنید.

## نکات مهم

- **بهینه‌سازی باتری**: در بسیاری از گوشی‌ها (شیائومی، سامسونگ، هوآوی و ...) باید اپ را از تنظیمات بهینه‌سازی باتری مستثنی کنید وگرنه ممکن است در پس‌زمینه متوقف شود.
- **هزینه‌ی پیامک**: ارسال پیامک فوروارد شده از طریق `SmsManager` مثل یک پیامک معمولی توسط اپراتور هزینه‌بر است (طبق تعرفه‌ی سیم‌کارت شما).
- **حریم خصوصی/قانونی**: فقط روی گوشی خودتان و با رضایت خودتان از این قابلیت استفاده کنید؛ فوروارد کردن پیامک‌های شخص دیگری بدون اطلاع و رضایت او می‌تواند از نظر قانونی مسئله‌ساز باشد.
- **محدودیت تطبیق شرط**: در حال حاضر شرط فقط بر اساس «شماره‌ی فرستنده» است. اگر بخواهید شرط‌های دیگری مثل وجود یک کلمه‌ی خاص در متن پیامک یا بازه‌ی زمانی خاص اضافه شود، تابع شرط در `SmsReceiver.onReceive` قابل گسترش است.
